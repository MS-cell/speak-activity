# Speak Activity Chatbot Refactor

## Overview
This project refactors the Speak Activity to integrate a Gen-AI (Generative AI) chatbot. The chatbot uses a pre-trained AI model (DialoGPT) from the HuggingFace library to provide natural, human-like conversations. It aims to enhance the learning experience of children by providing an interactive and engaging way to practice reading and spelling.

## Features
- **AI-based Chatbot:** Powered by DialoGPT to simulate conversations.
- **Spell Checking:** Uses PySpellChecker to correct common spelling mistakes.
- **Persona Customization:** The chatbot is designed to communicate in a simple, friendly tone suitable for children.
- **Educational Conversations:** The chatbot encourages learning through age-appropriate questions.

## Technologies Used
- **Python:** The main language used for development.
- **HuggingFace Transformers:** For implementing the Gen-AI model (DialoGPT).
- **PySpellChecker:** For spelling correction.
